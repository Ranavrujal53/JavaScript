Firestore's onSnapshot() creates a real-time listener that continuously watches the comments collection for changes. In the LiveCommentsFeed component, whenever a comment is added, updated, or deleted in Firestore, onSnapshot() receives the latest data automatically. The component updates the comments state using setComments(), which causes React to update the UI without refreshing the page. When the component is removed, the unsubscribe() function stops the listener and cleans up the connection.
