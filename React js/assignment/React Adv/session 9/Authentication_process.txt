### Firebase Authentication — Step-by-Step

1. **Open the Firebase Console** and select your `FirebaseReactDemo` project.

2. Go to **Authentication** from the Firebase project menu and click **Get started** if Authentication has not been enabled yet. ([Firebase][1])

3. Open the **Sign-in method** section.

4. Select the authentication provider you want to use, such as **Email/Password** or **Google**. Enable the provider and save the settings. ([Firebase][2])

5. Make sure Firebase is already initialized in the React application and the Firebase SDK is installed.

6. Add the **Firebase Authentication SDK** to the React application and initialize the Authentication service. Firebase's current Web SDK uses the modular `firebase/auth` API. ([Firebase][1])

7. Create a **Sign Up/Register** page where users can enter their email and password. Use Firebase Authentication's email/password sign-up functionality to create the account. ([Firebase][1])

8. Create a **Login** page where existing users can enter their email and password and sign in.

9. Add a **Logout** button so authenticated users can sign out of the application.

10. Use Firebase's **authentication-state observer** to detect when a user logs in or logs out. This allows React components to immediately update based on the current authentication state. ([Firebase][1])

11. Display the logged-in user's information, such as their email or user ID, in the application.

12. Test the complete authentication flow:

* Register
* Login
* Check logged-in user
* Logout
* Login again
